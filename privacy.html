Política de privacidad de BasuSICE

Última actualización: 29 de septiembre de 2026.

Responsable: Proyecto Verde Esperanza · Semillero SICE.
Autor: Mg. Erquinio Alberto Taborda Martinez.
Contexto institucional: IED San Gabriel · Barranquilla, Colombia.

1. Datos que puede tratar la aplicación

BasuSICE puede tratar nombre de participante, identificador de cuenta, registros de residuos, fecha y hora, ubicación GPS, recorrido, fotografías y datos de participación. Los datos científicos se utilizan para documentar actividades de ciencia ciudadana y análisis ambiental.

2. Ubicación y fotografías

La ubicación y la cámara solo deben utilizarse cuando la persona participante decida registrar una observación. Se recomienda evitar fotografiar rostros, documentos, placas u otros datos personales innecesarios.

3. Uso científico y educativo

Los registros pueden utilizarse para estadísticas, educación ambiental, informes y proyectos de investigación. La publicación de datos geográficos detallados debe revisarse antes de hacerse pública para evitar exponer información personal o sensible.

4. Almacenamiento offline

Los registros pueden permanecer temporalmente en el dispositivo sin conexión. Cuando existe servidor configurado, los datos pendientes pueden sincronizarse. La organización debe establecer políticas de conservación, respaldo y eliminación antes del despliegue definitivo.

5. Seguridad

La versión de producción debe desplegarse mediante HTTPS, utilizar una base de datos gestionada, contraseñas con hash seguro, copias de seguridad y control de acceso. No se debe utilizar una clave administrativa predeterminada.

6. Derechos y contacto

Las solicitudes sobre acceso, corrección o eliminación de datos deben dirigirse al responsable institucional que publique la aplicación. Esta plantilla debe completarse con el correo oficial, dirección institucional y demás datos legales antes de publicarla en una tienda de aplicaciones.
